# Omnifood

A responsive meal subscription landing page built with HTML, CSS and TypeScript.

Use Node 26.13.0 and npm 12.2.2. Run `npm ci`, then `npm run dev`.
Run `npm run build` to create a production build.

Based on Build Responsive Real-World Websites with HTML and CSS by Jonas Schmedtmann.
The design and photography come from the course assets.
This is a personal portfolio project and is not for redistribution.
